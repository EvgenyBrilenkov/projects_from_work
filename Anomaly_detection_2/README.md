# Anomaly Detection 2. Main

Данный репозиторий является продолжением, завершением и главной частью исследования моего прошлого репозитория Anomaly Detection.

В данном репозитории работа ведется с реальными данными, поэтому результаты изображений будут скрыты, а метрики будут заменены на ненастоящие, но при этом реалистичные. Основной упор репозитория сделан на код.

Весь код воспроизводится локально без подключения к интернету при заранее скачанных библиотеках и весах моделей.

В работе опробованы 3 метода машинного обучения:
* Обучение без учителя (алгоритмы anomalib: PaDiM, PatchCore, DRAEM)
* Обучение с частичным привлечением учителя (алгоритмы anomalib: PaDiM)
* Обучение с учителем (YOLO11-seg)

Главной целью работы является классификация изображений по наличию/отсутствию дефекта, при этом второстепенной задачей является выделение дефектной зоны для доказательства достоверности решения модели.

## Ход работы

### 1. Обучение без учителя

При получении реальных данных (около 2700 нормальных изображений и 300 дефектных) в первую очередь были опробованы алгоритмы библиотеки anomalib (подробнее об их работе в прошлом репозитории). 
На вход данных алгоритмов при обучении подаются нормальные (эталонные) изображения, алгоритмы запоминают их признаки. Во время теста подаются изображения с аномалиями. Алгоритмы, основываясь на признаках эталонных изображений, должны выявить расхождения нормальных участков и аномальных. При этом были интегрированы кастомные метрики, использован datamodule "Folder", а также использованы заранее скачанные feature extractors для запуска кода локально.

Для алгоритмов, учащихся в 1 эпоху (PaDiM и PatchCore) были опробованы 2 feature extractors:
* ResNet-18
* Wide ResNet-50-2

Для реализации алгоритма подбора параметров была выбрана библиотека optuna, при этом целевой метрикой выступила image_F1Score.

По итогам подбора параметров были сделаны выводы о том, что PaDiM быстро обучается и нормально классифицирует изображения, но плохо выделяет дефектные зоны, делая классификацию изображений безосновательной.
Что касается других алгоритмов, PatchCore и DRAEM требовали колоссальное количество времени для обучения и ресурсов, поэтому их подбор был остановлен.

### 2. Обучение с частичным привлечением учителя

После результатов первого этапа было принято решение разметить изображения, нарисовав для них сегментационные маски, чтобы:
1. Попробовать в качестве целевой метрики для optuna использовать pixel_F1Score
2. Попробовать YOLO для задачи сегментации

Изображения были размечены локально с помощью CVAT.

После разметки был также запущен подбор параметров с optuna и целевой метрикой pixel_F1Score для алгоритма PaDiM.

По итогам подбора PaDiM начал лучше детектировать дефектные зоны на дефектных изображениях, однако он стал гораздо чаще ошибаться на нормальных изображениях. Причиной этого могла стать сложная структура данных, и PaDiM, в свою очередь, мог не подойти для конкретной специфики данных.

### 3. Обучение с учителем

После экспериментов с алгоритмами anomalib и разметки данных было принято решение попробовать обучить YOLO. Для данной задачи были выбраны YOLO11s-seg (small) и YOLO11l-seg (large).

С помощью скрипта, написанного на Python все маски были переведены в txt формат, совместимый с YOLO. Количество тренировочных данных составило 228 изображений, количество валидационных - 74.

После обучения YOLO показала идеальные метрики на валидации как в задаче классификации, так и в задаче сегментации, при этом результат был идеален независимо от типа модели (small/large), из-за чего было принято решение интегрировать модель на производство. Для этого был написано полноценный скрипт, который будет подключен к камере. Для каждой детали будут сниматься 2 фотографии, которые при попадании в папку активируют работу функции скрипта. Для каждой детали создается папка с ее ID, в которую помещаются оригинальные изображения, изображения с предсказанием модели и вывод модели в текстовом виде. После каждой детали на экран также выводится общая статистика по отработке скрипта.
