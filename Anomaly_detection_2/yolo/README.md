## Архитектура директории

```
yolo  
|-- data.yaml  (указание путей к данным)
|-- files_renaming.py  (переименование файлов)
|-- from_mask_to_yolo.py  (конвертация масок в txt с координатами)
|-- production.py  (интеграция на производство)
|-- yolo11_training.ipynb (обучение yolo)
```

Для использования YOLO были созданы дополнительные скрипты:
* files_renaming.py - Переименование масок и дефектных изображений для соответствия формату названия файлов
* from_mask_to_yolo.py - Перевод изображения каждой маски в txt-файл с координатами для подачи в yolo
* production.py - Скрипт для работы модели на производстве, создающий под каждую сфотографированную деталь соответствующую директорию с оригинальными изображениями, изображениями с предсказаниями и txt-файл с выводом, а также выводящий статистику после каждой детали
