# Sea Objects Detection

Sea Objects Detection - проект, направленный на детекцию объектов на море на изображениях высокого разрешения (преимущественно 4k) с помощью обучения модели YOLO26m.

## Архитектура репозитория

```
Sea_objects_detection  
|  
|-- data_prep_scripts.ipynb (набор скриптов для подготовки данных)  
|-- yolo_training.ipynb (ноутбук с обучением модели)  
|-- pyramid_inference.ipynb (ноутбук с инференсом модели для изображений, видео и директории изображений с подсчетом метрик)  
|-- images (директория с изображениями для README)  
``` 

## Подготовка данных

В обучающей и валидационной выборке было выделено 6 классов объектов:

1. Корабль (ship)
2. Самолет (plane)
3. Вертолет (helicopter)
4. Морской буй (buoy)
5. Квадрокоптер/дрон (drone)
6. Человек на плоту (person)

Большая часть данных была собрана с помощью генерации сцен с движущимися объектами в Digital Combat Simulator World и записи видео в формате 4k и Full HD.  

Сцены были сгенерированы и отсняты вручную с разным наполнением, в том числе разными траекториями движения, разными углами съемки объектов, разными фонами (чистое море, острова, порты), разными погодными условиями (солнечно, облачно, дождь, туман), разным временем суток (утро, день, вечер). Сумерки были исключены из финального набора данных из-за невозможности детекции объектов при таких условиях освещения. Набор данных также был пополнен изображениями фона высокого разрешения при разных условиях.  

Для классов: корабль, самолет, вертолет, квадрокоптер/дрон набор данных был пополнен изображениями из открытых источников разного разрешения.

Все изображения с объектами были размечены вручную с помощью программы CVAT.

Для эффективности обучения, изображения, подаваемые в YOLO, сжимались до разрешения 640 x 640 (default).  
Однако данное сжатие гарантировало потерю мелких объектов на изображениях высокого разрешения.  
Эта проблема была решена разработкой алгоритма пирамиды разрешений, где на инференсе через YOLO будет проходить как оригинальное 4k изображение, сжатое до 640 x 640, для детекции крупных объектов, а также изображение будет нарезаться на кропы (тайлы) по 640 x 640 с перекрытием, все участки оригинального изображения будут проходить через YOLO батчем, и сработавшие детекции будут собираться в оригинальный кадр, подавляя неточные срабатывания с помощью кастомного NMS. Затем собранный по кусочкам кадр будет сравниваться с оригинальным кадром, подавляя детекции для одних и тех же объектов на разных этажах с помощью кастомного NMS с приоритетом детекций на оригинальном изображении.

Данный алгоритм пирамиды позволит находить как крупные объекты (при подаче оригинального изображения), так и мелкие объекты (при подаче кропов (тайлов/участков) оригинального изображения), не теряя их при сжатии на входе в модель.

Для создания эффективного набора для обучения были совершены следующие действия:

1. Оригинальные видео высокого разрешения были нарезаны на кадры
2. Из каждого видео были взяты каждые N-ные кадры (в зависимости от продолжительности видео) и размечены в программе CVAT
3. В набор данных были замешаны открытые данные (также размеченные в CVAT) и изображения с фоном (с созданной пустой разметкой)
4. Для кадров с артефактами (полоса с правой стороны, полоса панели управления) были обрезаны все артефакты с учетом сдвига разметки
5. Все кадры высокого разрешения были нарезаны на кропы по 640 x 640 с динамически высчитывающимся перекрытием (overlap) во избежание потери данных с кадра. Разметка также была нормализована для каждого кропа. Разметка для объектов на краю была удалена в случае, если на кадр помещается менее 50% объекта
6. Оригинальные изображения высокого разрешения также сохранялись в набор данных с удалением разметки для мелких объектов, площадь которых при сжатии становилась 0
7. Набор данных был прорежен от большого количества изображений без объектов, появившихся при нарезке оригинальных изображений
8. Набор данных был разделен на тренировочный и валидационный в пропорции 80/20 со стратификацией для равномерного распределения классов объектов между наборами

## Инференс модели

Для использования модели на тестовых данных (изображения, видео и директория с изображениями высокого разрешения) был написан скрипт, автоматически нарезающий изображения на кропы с динамически высчитывающимся перекрытием.  

Помимо нарезки и кастомного NMS, скрипт предоставляет возможность выбрать размер кропов для нарезки (необязательно использовать 640 x 640), а также количество этажей пирамиды.  
Рекомендуется использовать 2 этажа: оригинальное изображение (будет использован по умолчанию) и этаж с кропами по 640 x 640, однако есть возможность экспериментировать с разным количеством этажей и разрешениями, например: оригинальное изображение, этаж с кропами 1280 x 1280, этаж с кропами 640 x 640 и т.п.  

Скрипт также предоставляет возможность настроить все пороги (treshold) подавления сработанных детекций для одинаковых объектов внутри этажей и между этажами.  
Рядом с каждой детекцией отображается [global], если объект найден на оригинальном изображении, или [tiled], если объект найден при отработке модели на кропах.  

При подаче одного отдельно взятого изображения, помимо общего результата, пирамида дает возможность вывести результаты с каждого отдельного этажа.  
При подаче директории с изображениями пирамида дает возможность прикрепить директорию с разметкой и посчитать метрики качества отработки модели.
